# A3の既約パラメータ点での陰性割合（AV）

2026-10-19。next-44作業3。**二段条件を用いた漸近のAI証明案、Claude未点検**。
グラフへの結論はAUの完全条件の証明案に依存する。一般フラーレン全体の密度とは異なる。
鏡像・他の族との同型を再集計せず、指定された既約(k,l)を一組一票として数える。

## 1. 結論

N(k,l)=k²+kl+l²、k>l>0、gcd(k,l)=1とする。
D(T)をN≤Tの点数、P(T)をASの二段式が陽性と判定する点数、Z(T)=D(T)−P(T)とする。

    D(T) = T/(π√3) + O(√T log T),
    P(T) = Θ(√T log T),
    Z(T)/D(T) = 1 − Θ(log T/√T) → 1。

陰性割合の極限値は1。最後のΘは陽性割合に対する上下の次数であり、先頭定数は求めていない。
炭素数上限XではT=X/20と置き換える。

## 2. 陽性の上界

K=⌊√T⌋とすると全点でk≤K。m=min(l,k−l)に折り返すと、一つの(k,m)から元のlは高々2個。

- m=1：高々2K点。
- m≥2、q≥3：k=qm±1。各mに対しqは高々(K+1)/m、二符号と二つのlで高々4(K+1)H_K点。
- q=2、r=1：高々2K点。
- q=2、r≥2：m=sr±1、k=(2s+1)r±2、1≤r<m。
  各rに対してs≤(K+2)/(2r)。二符号と二つのlで高々2(K+2)H_K点。

ここでH_K=Σ_{j=1}^K 1/j。範囲を広げ、重複を許した上界なので

    P(T) ≤ 4K + (6K+8)H_K = O(K log K)。

有限Tでこの上界が全点数を超えても問題はない。定数の最適化はしていない。

## 3. 同じ次数の下界

L=⌊√(T/3)⌋、R=⌊(L−1)/3⌋とする。
2≤m≤R、3≤q≤⌊(L−1)/m⌋に対し(k,l)=(qm+1,m)を取る。
これは相異なる既約点で、k>3l、N≤3k²≤T、二段式で陽性。
点数は

    Σ_{m=2}^R (⌊(L−1)/m⌋−2)
      = (L−1)(H_R−1) + O(R) = Θ(L log L)。

したがってP(T)=Θ(√T log T)。有限サイズの一致を使わない式の議論である。

## 4. 既約点の分母

変換(x,y)=(k+l/2,√3 l/2)でN=x²+y²となり、k>l>0は角幅π/6の扇形になる。
半径√Tの扇形面積πT/12をヤコビアン√3/2で割ると、元の面積はπT/(6√3)。
境界長がO(√T)なので、整数点数A(T)はこの面積にO(√T+1)を加えたものとなる。
各点のgcdで分け、Möbius反転を使えば

    D(T)=Σ_{d≤√T} μ(d) A(T/d²)
        = [π/(6√3)]T Σ_{d≥1} μ(d)/d² + O(√T log T)。

Σμ(d)/d²=1/ζ(2)=6/π²より上の係数を得る。
開いた境界や固定個の小さい点は誤差項へ入る。
原始点の一般的な密度に新規性を主張しない。新しい内容の候補は二段条件から陽性の次数を絞る帰結である。
